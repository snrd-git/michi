# Nihongo Michi

Aplikasi belajar bahasa Jepang N5–N1 (offline, PWA): teori, kartu ulang, Akselerator 80/20, latihan per tipe soal JLPT, ujian penuh/mini dengan perkiraan skor 0–180, dan rencana belajar.

Buka: https://snrd-git.github.io/

Soal di aplikasi ini orisinal bergaya JLPT, bukan soal ujian resmi.
